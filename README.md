# تقرير المعتمرين الأفراد

نسخة مستقلة للاستخدام في اجتماعات القيادات والنشر عبر GitHub Pages أو داخل بيئة الجهة.

## الملفات

- `index.html`: صفحة العرض.
- `weekly-data.json`: بيانات الأسبوع المرجعية لتسهيل التحديثات القادمة.

## التحديث الأسبوعي

يُحدّث رقم الأسبوع وتاريخ البيانات والمؤشرات في `weekly-data.json`، ثم تُراجع النصوص الظاهرة في `index.html` قبل النشر. يحتفظ الملف بنفس أسماء المؤشرات أسبوعًا بعد أسبوع لتقليل أخطاء النقل.
